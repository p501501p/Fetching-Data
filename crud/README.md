# ระบบจัดการข้อมูลนักศึกษา (Student Management)

โปรเจกต์นี้เป็นเว็บแอปพลิเคชันสำหรับจัดการข้อมูลนักศึกษาแบบ CRUD (Create, Read, Update, Delete) โดยพัฒนาด้วย Next.js, Prisma และ SQLite เพื่อให้ผู้ใช้งานสามารถเพิ่ม แก้ไข และลบข้อมูลนักศึกษาได้อย่างง่ายดาย

## ภาพรวมของระบบ

ระบบนี้ออกแบบมาเพื่อช่วยให้บุคลากรหรืออาจารย์สามารถจัดการข้อมูลนักศึกษาได้ เช่น

- ดูรายชื่อนักศึกษา
- เพิ่มข้อมูลนักศึกษาใหม่
- แก้ไขข้อมูลนักศึกษา
- ลบข้อมูลนักศึกษา
- ตรวจสอบสถานะการศึกษา

ข้อมูลทั้งหมดถูกเก็บในฐานข้อมูล SQLite 
## เทคโนโลยีที่ใช้

- Next.js
- React
- TypeScript
- Prisma ORM
- SQLite
- Tailwind CSS

## ข้อกำหนดเบื้องต้น

ก่อนติดตั้งโปรเจกต์ กรุณาตรวจสอบว่ามีสิ่งต่อไปนี้บนเครื่องของคุณแล้ว

- Node.js เวอร์ชัน 18 ขึ้นไป
- npm หรือ pnpm
- Git (ถ้าต้องการ clone จาก repository)

## วิธีการติดตั้ง

1. Clone โปรเจกต์จาก repository

```bash
git clone <repository-url>
cd crud
```

2. ติดตั้ง dependency ทั้งหมด

```bash
npm install
```

3. ตรวจสอบไฟล์ `.env`

โปรเจกต์ได้กำหนดค่า `DATABASE_URL` ไว้แล้วในไฟล์ `.env` โดยค่าเริ่มต้นคือ

```env
DATABASE_URL="file:./dev.db"
```

หากต้องการเปลี่ยนตำแหน่งฐานข้อมูล สามารถแก้ไขค่าในไฟล์นี้ได้

4. สร้างฐานข้อมูล Prisma

```bash
npx prisma generate
npx prisma db push
```

หรือต้องการให้ Prisma สร้างตารางตาม schema แบบอัตโนมัติ ให้ใช้คำสั่งต่อไปนี้

```bash
npx prisma migrate dev --name init
```

## การใช้งาน

### รันโครงการแบบ Development

```bash
npm run dev
```

หลังจากรันสำเร็จ ให้เปิดเบราว์เซอร์ไปที่

```text
http://localhost:3000
```

### เข้าถึงหน้าเมนูจัดการนักศึกษา

```text
http://localhost:3000/students
```

ที่หน้านี้จะมีฟังก์ชันดังนี้

- ดูรายชื่อนักศึกษา
- เพิ่มนักศึกษาใหม่
- แก้ไขข้อมูลนักศึกษา
- ลบข้อมูลนักศึกษา

### หน้า Skeleton Loading

โปรเจกต์มีตัวอย่างหน้าแสดงสถานะ Loading แบบ Skeleton ไว้ที่เส้นทางต่อไปนี้

```text
http://localhost:3000/skeleton
```

หน้าดังกล่าวใช้ Tailwind CSS ร่วมกับ class `animate-pulse` เพื่อจำลองการโหลดข้อมูลแบบ card skeleton โดยจะแสดงบล็อกสีเทาในรูปแบบ 3 คอลัมน์สั้น ๆ เพื่อให้ผู้ใช้งานเห็นว่าเว็บไซต์กำลังโหลดข้อมูลอยู่ก่อนที่ข้อมูลจริงจะแสดงผล

ไฟล์ที่เกี่ยวข้อง:

```text
app/skeleton/page.tsx
```

### รันโครงการแบบ Production

สำหรับการ build และรันเวอร์ชัน production

```bash
npm run build
npm run start
```

## การอธิบายระบบแบบย่อ

ระบบนี้มีจุดประสงค์เพื่อใช้เป็นแอปพลิเคชันจัดการนักศึกษาในระดับพื้นฐานที่เหมาะสำหรับการศึกษาและการสาธิตงาน CRUD โดยอาจารย์หรือผู้ดูแลสามารถใช้งานได้โดยตรงผ่านหน้าเว็บ โดยข้อมูลจะถูกบันทึกลง SQLite และเรียกใช้งานผ่าน Prisma ORM ทำให้การจัดการข้อมูลเป็นไปอย่างสะดวกและมีประสิทธิภาพ

## ปัญหาที่อาจพบและแนวทางแก้ไข

- หากเกิดข้อผิดพลาดเกี่ยวกับ Prisma ให้รันคำสั่งต่อไปนี้

```bash
npx prisma generate
```

- หากฐานข้อมูลไม่ปรับปรุงตาม schema ให้รัน

```bash
npx prisma db push
```

- หากต้องการเริ่มต้นใหม่ด้วยฐานข้อมูล SQLite ให้ลบไฟล์ `dev.db` และรันคำสั่งสร้างฐานข้อมูลอีกครั้ง
